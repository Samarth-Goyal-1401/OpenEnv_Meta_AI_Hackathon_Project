# Foundation Docs

This folder contains internal hackathon process documents and team operating guidelines that used to live at the repo root. They are kept here to make the GitHub project view cleaner.

## Index

- `TEAM_RULEBOOK.md`: team rules and "sacred file" ownership constraints
- `RULES.md`: hard guardrails for OpenEnv hackathon compliance
- `HACKATHON_CHECKLIST.md`: submission flight checklist
- `OPENENV_COMPLETE_GUIDE.md`: end-to-end OpenEnv learning/reference guide
- `TECH_STACK.md`: setup and versioning constraints
- `SYSTEM_PROMPT.md`: copilot system prompt used during development

- `ENGINEERING_WORKFLOWS.md`: engineering workflows and best practices used in the project
- `DOMAIN_DESIGN_TEMPLATE.md`: domain brainstorming template
- `IMPLEMENTATION_ROADMAP.md`: step-by-step implementation plan
- `AI_MERGE_PROTOCOL.md`: merge ceremony protocol for collaborating safely
- `MERGE_GUIDE_FOR_DEVS.md`: merge guide for the team
- `MERGE_CEREMONY_REPORT.md`: record of a merge ceremony

- `MISTAKES.md`: session continuity log and pitfalls
- `STRATEGIC_COMPACTION.md`: memory/context management notes for long sessions
- `SANITATION_AUDIT.md`: sanitation audit log
- `handoff.md`: teammate handoff notes
